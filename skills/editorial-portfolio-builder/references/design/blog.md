## Section 4 — 文章阅读视图（Reader Overlay / 或 `/blog/[slug]`）

**布局**：全屏杂志文章版式，纸白底，顶部细进度条（信号橙，随滚动 scaleX 增长）：
- 文章头：mono 分类+日期 → 超大标题（Noto Serif SC 64px）→ mono 元信息行 "WORDS 4,200 / READ 14 MIN / 陈未远 著" → 1px 墨线 → 全宽头图（黑白）
- 正文：单栏居中，最大宽 720px，Noto Sans SC 17px/1.9；排版细节：首字下沉（首段首字 Noto Serif SC 96px 墨黑下沉三行）、小节标题 Noto Serif SC 32px 带 mono 编号、行内代码 JetBrains Mono 橙底浅块、代码块墨黑底纸白字 + 左上角 mono 文件名标签、引用块左侧 4px 橙色竖线 + 斜体衬线
- 正文内容：每篇文章准备 3–5 小节精美占位文案（围绕标题主题的真实感技术随笔，各 200–400 字）

**动画**：打开时整页从右侧 wipe 入；标题字符级落下；正文按段落块级随滚动上浮（stagger 依据视口）；进度条 scrub。
**交互**：代码块 hover 显示 "COPY" 按钮（复制 + 印章反馈）；点击目录（如有）平滑滚动锚点。
