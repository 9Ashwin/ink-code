# Global Design Document — "INK & CODE" 开发者作品集（杂志编辑风）

## 项目概述

一个面向程序员/工程师的个人简历 + 作品展示网站。视觉采用**杂志编辑风（Editorial Magazine Style）**：大胆字体、拼贴感排版、超大刊号数字、撕纸边缘、印章标签、半调网点纹理、跨栏排版。整体气质像一本独立技术杂志的特刊——主角是"这位工程师"。

所有内容为精美的占位示例（虚构人物 **陈未远 / Chen Weiyuan**，全栈工程师），用户后续自行替换。站点语言以中文为主，配合大量英文展示字体做编辑排版对比（杂志刊头惯例）。

---

## 视觉方向

- **风格关键词**：editorial / collage / ink on paper / oversized type / grid-breaking / risograph 印刷感
- **质感**：米白纸底 + 墨色黑字 + 单一高饱和强调色（信号橙），局部半调网点、噪点颗粒、手绘圈注、胶带/撕纸元素
- **排版原则**：不对称网格；标题允许出血、旋转（-2°~3°）、跨越图片；正文区域反而克制、易读（编辑杂志的"闹中取静"）
- **禁止**：渐变玻璃拟态、圆角 SaaS 卡片、紫蓝科技感渐变。这是一个"纸质刊物"，不是 SaaS landing

| 角色 | 色值 | 用途 |
|---|---|---|

| Ink（墨黑） | `#14120E` | 主文字、深色区块背景 |
| Ink Soft | `#3A362F` | 次级文字 |
| Signal（信号橙） | `#FF4D00` | 强调色：刊号、链接 hover、印章、下划线、游标 |
| Blueprint（蓝图蓝） | `#2B4BD8` | 仅用于代码块/技术标签的点缀（少量） |

深色区块（如首页"技术栈"整版）反转为：底 `#14120E`，文字 `#F4F1EA`，强调色不变。

## 字体

Google Fonts 引入：

| 用途 | 字体 | 说明 |
|---|---|---|
| 英文展示标题 | **Archivo Black**（或 Anton） | 超大、超粗、紧凑行距，用于刊头、页面大标题、数字 |
| 中文标题 | **Noto Serif SC**（700/900） | 衬线中文标题，制造"杂志大标题"感 |
| 中文正文 | **Noto Sans SC**（400/500） | 正文可读性 |
| 等宽 / 代码 / 元信息 | **JetBrains Mono**（400/500/700） | 日期、编号、标签、代码、技术栈——"工程师"身份的视觉签名 |

字号系统（桌面 / 移动）：
- Display（刊头级）：`clamp(64px, 12vw, 160px)`，行距 0.9，Archivo Black，大写，letter-spacing -0.02em
- H1（页面标题）：`clamp(48px, 8vw, 110px)`
- H2（板块标题）：`clamp(32px, 5vw, 64px)`
- H3：24–28px
- 正文：16–17px，行距 1.75
- 元信息（mono）：12–13px，大写，letter-spacing 0.08em

## 间距与网格

- 页面最大宽度 1440px，左右边距桌面 48px / 移动 20px
- 12 栏网格，但鼓励"破栏"：元素跨栏、出血、叠加
- 板块垂直间距 120–180px（桌面）
- 所有卡片/容器**直角或 2px 微圆角**，用 1px 墨线边框 + 硬阴影（`4px 4px 0 #14120E`）代替柔和阴影——印刷拼贴感

## 动画风格

- **滚动**：Lenis 全局平滑滚动
- **进场**：以"印刷落版"为隐喻——文字像铅字落下：字符级 SplitText 上滑 + 轻微旋转回正（`y: 40px→0, rotate: 3deg→0, opacity 0→1, stagger 0.03s`）
- **滚动驱动**：GSAP ScrollTrigger 驱动的横向卷动（作品列表）、视差拼贴层、整版 pin 住的章节切换
- **微交互**：Framer Motion——hover 时图片抖动位移、印章"盖下"动画（scale 1.4→1 + rotate）、按钮墨块填充（从左向右 wipe）
- **Marquee**：无限滚动的横向文字带（刊名、技术栈关键词），速度随滚动速度轻微联动
- 同时动画元素 ≤ 8；文字动画：标题字符级（≤20 字符）、副标题词级、正文块级

## 光标

- 自定义光标：16px 信号橙圆点 + 36px 描边圆环跟随
- hover 可点击元素时：圆环放大至 64px，内部显示 mono 小字（如 "VIEW" / "READ" / "OPEN"）
- 移动端禁用自定义光标

## 共享组件

### Navbar（全站）
- 顶部固定，纸白底 + 底部 1px 墨线
- 左：刊头 logo "C.W.Y — INK & CODE®"（Archivo Black + mono 小字 "VOL.01 — 2025"）
- 中：导航链接（首页 / 作品 / 经历 / 写作 / 联系），mono 大写小字，hover 出现信号橙下划线动画（scaleX 0→1，origin left）
- 右：GitHub / 博客 / 邮箱图标链接 + "可接单 / Open to Work" 状态点（绿色脉冲圆点 + mono 字）
- 移动端：汉堡菜单 → 全屏墨黑抽屉，链接以超大衬线中文 + 英文编号纵向排列，逐个 stagger 进场
- 滚动时 Navbar 收缩：高度 80px→56px，背景加轻微噪点纹理

### Footer（全站）
- 墨黑整版底，巨型刊名 "WEIYUAN.CHEN" 出血横贯底部（纸白色，半透明 8%，作为背景纹理字）
- 三栏：站点地图 / 社交链接（GitHub、掘金、X、RSS）/ 版权与 "Designed & Built by Chen Weiyuan, 2025 · 本刊为虚构占位内容"
- 顶部一条 marquee："KEEP SHIPPING — 持续交付 — STAY CURIOUS — 保持好奇 —" 循环
- 回到顶部按钮：圆形印章样式，hover 旋转

### 通用组件
- **Section Header**：mono 编号（"01 —"）+ 信号橙短横线 + 大标题 + 右侧可选副注
- **Stamp**：圆形/矩形印章元素，红橙色描边 + 旋转 -8°，文字如 "FEATURED / 精选"、"NEW / 新"、"OPEN SOURCE"
- **Tape**：半透明米色胶带贴图（CSS 渐变模拟），用于"贴住"图片角
- **Tag**：mono 小字 + 1px 墨线描边胶囊，用于技术栈标签
- **Halftone 背景**：CSS radial-gradient 点阵纹理，用于区块过渡带

## 依赖

- React 19 + TypeScript + Vite 7
- Tailwind CSS 3.4（自定义色板/字体映射上述 token）
- GSAP + ScrollTrigger（滚动叙事、pin、SplitText 风格动画——SplitText 用自实现字符拆分代替）
- Framer Motion（页面过渡、微交互、弹层）
- Lenis（平滑滚动）
- shadcn/ui（Dialog、Accordion、Tabs 作为底层交互基元，样式全部覆写为编辑风）
- lucide-react（图标）

## 页面过渡

- Framer Motion `AnimatePresence`：页面切换 = 墨黑色块从左侧 wipe 覆盖（0.5s）→ 新页面从下方 24px 淡入（0.4s）
- wipe 层上显示下一页刊号大字（如 "VOL.02 — WORKS"）
