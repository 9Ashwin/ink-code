# editorial-portfolio-builder — 墨色杂志编辑风作品集 · 一站式复刻

一个技能 = 完整工作流 + 完整设计系统 + 全部原始蓝图与素材。目标：把一个"帮我做个
简历/作品集网站"的需求，复刻成"INK & CODE"那种独立技术杂志特刊质感的站点。

## 它长什么样（一眼确认风格）

米白纸底上的墨色印刷品：超大 Archivo Black 英文刊头 + 中文衬线标题对比排版、
信号橙做刊号/印章/下划线点缀、撕纸边缘、胶带贴照片、半调网点、1px 墨线卡片 +
硬阴影、字符级"铅字落版"动画、Lenis 平滑滚动 + GSAP 滚动叙事、自定义杂志光标。
**反面清单**：禁渐变玻璃拟态、禁圆角 SaaS 卡片、禁蓝紫科技感渐变。

## 复刻快速路径（最高优先级）

目标是复刻原站时，照此执行，不要重新发明：

1. **读蓝图**：`references/design/design.md`（全局）+ 5 份页面 md 就是原站的完整
   设计文档，直接作为设计师阶段的产出使用——**跳过重新设计**，除非用户要求改动。
2. **搬素材**：`assets/images/` 的 14 个文件就是原站实际使用的图片（黑白高对比
   人像 ×2、项目封面 ×5、文章封面 ×4、桌面俯拍、颗粒纹理、刊头 SVG，已做版权水印
   清理与目检），全部复制到项目 `public/`。注意：设计文档里的文件名是 `.png`，素材包
   为压缩体积存为 `.jpg`，引用时统一用 `.jpg`（或在设计文档基础上全局替换扩展名）。
   若要替换素材：**图搜素材必须逐张目检水印**（常藏在底部白条），优先用图像生成工具自产。
3. **铺 token**：`assets/editorial.tailwind.js` 合并进 tailwind 配置、
   `assets/editorial.css` 合并进全局 CSS、HTML 引入 Google Fonts（链接在 css 头注释）。
4. **按流程建站**：走下面的工作流（设计阶段已被第 1 步替代）。

## 工作流（设计先行 + 契约隔离 + 页面并行 + 阶段门禁）

```
Stage 0 需求确认 → Stage 1 设计(复刻时被"读蓝图"替代)
→ Stage 2 脚手架(共享组件+首页+素材) → 门禁逐项 grep 核对
→ Stage 3 每页 1 个子代理并行 → Stage 4 主代理逐个合并+构建
→ Stage 5 保存版本交付
```

1. **Stage 0**：一次问完——① 职业方向 ② 确认沿用编辑杂志风 or 要调整 ③ 占位内容 or 真实信息
2. **脚手架契约清单**（验收必查，漏一项后面全歪）：Navbar/Footer/Layout 三件套存在、
   全部路由有 stub、Layout 与 App 的 `{children}`/`<Outlet/>` 模式一致（混用=白屏但
   build 通过）、Navbar 用 `sticky`（`fixed` 必须配 Layout 顶部补偿）、占位人物姓名与
   字体全站唯一、共享基元（SectionHeader/Stamp/Tag/Tape/Halftone）已建、`public/` 素材齐
3. **页面代理作用域**：只准动 `src/pages/X.tsx` + `src/components/<x>/`；
   数据文件只归一个代理；弹层/阅读视图用 state 驱动（路由归 App）
4. **合并**：逐个分支 merge（不用 octopus）；多代理加同一依赖时 package.json 取并集、
   lock 用 `--ours` + `npm install` 调和；之后 fresh install + build exit 0 才交付
5. **交付**：静态站保存版本即交付，旧版本可回滚

完整操作手册（子代理 prompt 模板、验收命令、踩坑案例库）：读 `references/workflow.md`。

## 动画红线（原站修过的真 bug）

- GSAP scrub 时间线**必须用 `fromTo()`**，禁 `from()`（终值会被烘烤成透明态，元素不可见）
- 文字动画：标题字符级（≤20 字符，stagger 0.03s）、副标题词级、正文块级；同屏动画 ≤ 8
- 印章"盖下"：`scale 1.4→1 + rotate→-8°`，elastic

## 页面结构（原站 5 页，可按职业裁剪）

`/` 杂志封面 Hero + 目录条 + pin 横向卷动精选作品 + 黑版技术栈 + 履历摘要 + 文章索引 + CTA ·
`/projects` 目录式大索引（hover 浮出大图）+ 筛选 + 报道式详情弹层 ·
`/about` 人物特稿 + 数据速览 + 竖向时间轴 + 技能矩阵 + 证书/PDF 卡 ·
`/blog` 文章网格 + 杂志阅读视图（首字下沉/代码块/进度条） ·
`/contact` 信纸表单 + 编辑部信息栏 + FAQ。

工程底座依赖环境技能 `vibecoding-webapp-swarm`（init 脚本/worktree/版本工具），本技能不重复其脚本用法。
